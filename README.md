🤖 Automação de Cadastro de ProdutosEste projeto é uma automação desenvolvida em Python que realiza a leitura de uma base de dados local e cadastra automaticamente as informações em um sistema web. 

O objetivo é eliminar o trabalho manual e reduzir erros de digitação.

🚀 FuncionalidadesLeitura de base de dados (CSV ou Excel).

Navegação automática pelo sistema web.
Preenchimento de campos de formulário (Nome, Categoria, Preço, etc.).
Envio automático de dados.

🛠️ Tecnologias Utilizadas

Python 3.x
Pandas: Para manipulação e leitura da base de dados.
PyAutoGUI: Para automação da interface e cliques.
